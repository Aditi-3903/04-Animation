# 04-Animation

## Project Overview
This project is created for **learning purposes** to understand and practice animation techniques in React.

## Technologies Used
- **React** - JavaScript library for building user interfaces
- **GSAP (GreenSock Animation Platform)** - Professional animation library for smooth and performant animations

## Features
- Smooth animations using GSAP
- Interactive animation examples
- Learning-focused code structure



## Purpose
This is a learning project to explore and master GSAP animations within a React application.
